# Doclin IntelliJ Plugin

## Prerequisites

Before running the plugin, ensure you have the following installed:

1. **IntelliJ IDEA IDE**
    - Download from [JetBrains](https://www.jetbrains.com/idea/download/)

2. **Kotlin Plugin**
    - Ensure the Kotlin plugin is installed in IntelliJ. You can install it from the Plugin Marketplace in IntelliJ.

3. **IntelliJ Plugin DevKit**
    - This is required for developing and running plugins. Install it through the Plugin Marketplace in IntelliJ.

## Running the Plugin

To run the plugin:

1. Open IntelliJ IDEA.
2. Select the **Run Plugin** configuration.
3. Hit **Run**.
4. A new instance of IntelliJ IDEA will open with the plugin loaded.
5. In the new instance, create an **empty project**.
6. Once the project is open, you should see the plugin on the **right side** of the IDE.
